# Cyprus Discovery

Cyprus Discovery is a React project that helps users discover selected places in Northern Cyprus.

The app uses Google Places API to show real place information such as:

- Place name
- Rating
- Review count
- Address
- Photo
- Google Maps link

## Regions

- Mağusa
- Girne
- Lefkoşa
- İskele
